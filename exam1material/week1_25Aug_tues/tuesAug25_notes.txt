Taking a step back...what is logic?

- analysis of an argument according to a set of rules
- given a set of premises (and sometimes a conclusion)


- a VALID conclusion is one that is always true
    anytime all the premises are true


Note that the premises might make no sense!

When we have an "if/then" statement,
and we know that the "if" part is true?

    ...what can we always conclude?


the then part is true 


/////////////////////////////////////////////////////////

If I don't hear my alarm, then I will be late for class.
I am late for class.

--> What can I conclude? NOTHING.

I could have heard my alarm but still been late. 

(the if-then promise is only in one direction)


/////////////////////////////////////////////////////////

If I don't hear my alarm, then I will be late for class.
I hear my alarm.

--> What can I conclude? 

NOTHING. Could have been late for other reasons (or not late)





/////////////////////////////////////////////////////////

If I don't hear my alarm, then I will be late for class.
I'm not late for class.

--> What can I conclude? 


either hear the alarm or didn't hear the alarm 
CAN'T be the case that I didn't hear my alarm, because this
    would mean that I was both late and not late

MUST be the case that I heard my alarm.


is equivalent to (called the contrapositive):

If p Then q     is equivalent to... If not q Then not p







if (condition) {
    statement
}

--> what if we know statement is NOT executed? 


If condition, Then statement

If Not statement, then not condition

More if/then logic in programming.


if (num < 4 || x >= 10) {

    y = 17;
}

--> suppose y is 17 here. What do we know?

NOTHING. y might have been 17 before the if statement, or 
one of the conditions (or both) in the if might have been true.

/////////////////////////////////////////////////////////

y = 10;
if (num < 4 || x >= 10) {

    y = 17;
}

--> suppose y is 17 here. Can we conclude anything now?
we know one or both sides of the if was true because y changed to 17


//////////////////////////////////////////////////////////

if (num < 4 || x >= 10) {

    y = 17;
}

--> suppose y is NOT 17 here. What do we know?

num < 4 || x >= 10 was false

both conditions false
num >= 4 AND x < 10

What are Eve and Fred? both knights

    would make her full statement true.
